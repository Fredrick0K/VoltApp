1. SMART RECOMMENDATIONS
(“Best hour for laundry”, “Worst hour to shower”, etc.)

1.1. Define the data you need
24h price curve (hour → price)

User’s preferred time windows

Appliance duration (1h, 2h, etc.)

Market timezone

1.2. Add a recommendation engine layer
A module that:

receives the 24h price list

filters hours based on user preferences

finds the cheapest hour

finds the most expensive hour

returns structured recommendation data

This becomes a reusable service.

1.3. Integrate with your ViewModel
Fetch prices

Fetch user profile

Generate recommendations

Expose them to UI

1.4. Add UI components
“Best hour” card

“Worst hour” warning

Icons for each appliance

Color coding (green = good, red = bad)

1.5. Add optional notifications
“Cheapest hour starts in 30 minutes”

“Peak hour incoming”

1. core/
Shared utilities, DI modules, extensions, constants.

util/ → date/time helpers, price formatters

extensions/ → Kotlin extension functions

di/ → Hilt modules (repositories, engines, API clients)

2. data/
Everything related to fetching, storing, and caching data.

api/
client/ → Retrofit client

dto/ → raw API response models

adapters/ → Spain API adapter, future France/Germany/NordPool adapters

This is where multi‑market support will live.

local/
datastore/ → user profiles, preferences

cache/ → last known prices, offline mode

repository/
PriceRepository

ProfileRepository

MarketRepository (future)

Repositories combine API + local storage.

3. domain/
Your business logic layer.

model/
Clean models used by the app (not DTOs).

usecase/
Each feature gets its own use case:

GetDailyPricesUseCase

GetRecommendationsUseCase

EstimateConsumptionUseCase

GetElectricityMoodUseCase

engine/
Your “smart” logic:

recommendation engine

consumption estimator

mood calculator

This is where the intelligence of the app lives.

4. ui/
Each screen gets its own folder.

main/
Main screen showing:

price list

chart

mood

recommendations

profile/
User selects appliances, time windows, durations.

estimator/
Wattage + duration → cost calculator.

settings/
Theme, notifications, region selection (future).

components/
Reusable UI elements:

price card

mood indicator

recommendation card

5. widget/
Home screen widget logic:

update service

layout

broadcast receiver

6. theme/
Material 3 theme, colors, typography.
